# Graph-Based Cybersecurity Attack Detection

## 📌 Project Overview
This project detects cyber attacks using graph-based techniques on the CICIDS dataset.

## 🚀 Features
- Graph modeling using NetworkX
- Attack detection using labels
- VF2 subgraph matching algorithm
- Interactive visualization (click nodes)
- Color-based attack highlighting

## 🧠 Technologies Used
- Python
- NetworkX
- Matplotlib
- Pandas

## 📊 Dataset
CICIDS 2018 dataset is used for analysis.

## 🎯 Output
- Attack flows highlighted in red
- Benign flows in blue
- Interactive graph visualization
